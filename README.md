# Consulta de previsión meteorológica semanal usando Open-Meteo API.

- Múltiples ubicaciones en bucle
- Resultados en pandas DataFrame
- Persistencia en SQLite (weather.db)

No requiere API key. Documentación: https://open-meteo.com/en/docs

Dependencias: 
pandas para uso de dataframes 
plotly y streamlit para la aplicación interactiva 


## 🚀 Características
- **Consulta por Ciudad:** Obtén el clima actual y el pronóstico de los próximos días.
- **Visualización de Datos:** Gráficos dinámicos de temperatura y humedad.
- **Interfaz Moderna:** Diseñada para ser intuitiva y responsive con Streamlit.
